# Implementando-sua-Primeira-Stack-com-AWS-CloudFormation
Desafio do Bootcamp Code Girls 2025 da DIO

💻 Para este desafio o objetivo é praticar a automação de infraestrutura em nuvem por meio da criação e execução de templates em YAML/JSON. Durante a atividade, serão desenvolvidos projetos práticos que simulam desafios reais, como a criação de instâncias EC2, configuração de servidores web e implementação de regras de segurança. A proposta é aplicar conceitos de Infraestrutura como Código (IaC), explorando versionamento, reutilização de templates e boas práticas no provisionamento de recursos na AWS.

## ❓ Como foi realizado este desafio?

Para este desafio, seguiu-se alguns templates para automatização de infraestrutura em nuvem. Os templates estavam em formato YAML e realizamos a criação de:
+ instâncias EC2
+ configuração de servidores web
+ Aplicações de regras de segurança
+ Criação de usuários

📔 Neste repositório você irá encontrar:

+ "[images](images/)": pastas separadas com prints de tela mostrando os resultados obtidos em cada template aplicado.
+ "[codes](codes/)": pastas separadas com os códigos de cada template.

## ❓Qual a importância de aprender a automatização por meio de execução de templates?

Ao lidar com os recursos da AWS no dia a dia, a criação de um grande volume de recursos ou a especificação de redes e regras complexas pode ser demorada e propensa a erros se feita manualmente pelo console. A automação via templates agiliza essas tarefas, tornando o processo mais rápido e preciso, o que permite a implementação de infraestruturas ainda mais robustas e confiáveis.
